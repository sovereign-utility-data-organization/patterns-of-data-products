# Knowledge Concepts

* [data-product](/knowledge-concepts/data-product) - What a data product is: data + contract + interface; the interface model (3 patterns × 2 sides → 7 side states → 7×7 = 49 types)
* [pattern-batch](/knowledge-concepts/pattern-batch) - Batch (B): bulk/file on a schedule, on input or output side
* [pattern-request-response](/knowledge-concepts/pattern-request-response) - Request/response (R): synchronous on-demand query; polling upstream or serving APIs
* [pattern-streaming](/knowledge-concepts/pattern-streaming) - Streaming (S): continuous pub/sub push; event consumption or feed serving
* [synthetic-stream](/knowledge-concepts/synthetic-stream) - Pseudo-streams: the 12 cells that serve S without ingesting S, and the contract items they need
* [cross-cutting-observations](/knowledge-concepts/cross-cutting-observations) - Structural properties of the 49-type space: pass-through diagonal, batch core, state vs. cost
